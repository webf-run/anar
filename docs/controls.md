# Form states

Web form controls exhibit one or more of these states:

- Pristine - the untouched or default state.
- Empty state - No data filled.
- Filled state - Data is filled.
- Editable
- Read-only
- Disabled
- Error
- Loading
- Active
- Focus/hover
- Keyboard focus

And, they may be in more than that one state at any point:

- Read-only + Error.
- Empty + Error.
- Active + Error.
- Disabled + Empty.
- Disabled + Filled.
